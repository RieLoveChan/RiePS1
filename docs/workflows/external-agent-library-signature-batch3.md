# Exact owned inventory

The owned set is exactly the rows in the fixed-base
`docs/games/ddr5thmix/symbol-map.csv` satisfying all of these predicates:

- `confidence == library_signature`;
- `source_status == decompiler_output_only`;
- `overlay == main`;
- non-empty `proposed_name`;
- `address` begins with `0x8`;
- integer `size` is in the inclusive range 8–16 bytes.

Sorted lexically by `address`, the canonical UTF-8 inventory is one
`address,size,proposed_name` row per function, LF-terminated. At the fixed base
it contains **140 unique functions / 1,564 bytes** and has SHA-256:

`ede6b69b27c4f02b000c58161823be0769fbbe0e92c21faf97555d35a613ffd1`

Reproduce the inventory from the package root:

```powershell
$rows = Import-Csv docs/games/ddr5thmix/symbol-map.csv |
    Where-Object {
        $_.confidence -eq 'library_signature' -and
        $_.source_status -eq 'decompiler_output_only' -and
        $_.overlay -eq 'main' -and
        $_.proposed_name -and
        $_.address -match '^0x8' -and
        [int]$_.size -ge 8 -and
        [int]$_.size -le 16
    } |
    Sort-Object address

$inventory = (($rows | ForEach-Object {
    "$($_.address),$($_.size),$($_.proposed_name)"
}) -join "`n") + "`n"

$sha256 = [Convert]::ToHexString(
    [Security.Cryptography.SHA256]::HashData(
        [Text.Encoding]::UTF8.GetBytes($inventory)
    )
).ToLowerInvariant()

if ($rows.Count -ne 140 -or
    ($rows | Measure-Object size -Sum).Sum -ne 1564 -or
    $sha256 -ne
        'ede6b69b27c4f02b000c58161823be0769fbbe0e92c21faf97555d35a613ffd1') {
    throw 'Batch-3 inventory does not match the fixed contract.'
}
```

This deliberately excludes the synthetic one-byte GTE macro entries at
`0x20000000` and every function larger than 16 bytes. Do not substitute,
rename, add, or drop functions. Inferred `<OBJECT>_OBJ_<offset>` labels are
inventory identities only; do not promote them into claims about original
PsyQ filenames, semantic object identity, or confirmed linked-object
boundaries.

# Reconstruction rules

1. Recover each bounded function from the hash-gated executable and express it
   as readable MIPS assembly using instruction mnemonics, labels, symbols, and
   explicit load/branch delay slots.
2. Do not use `incbin`, reference slices, generated byte arrays, or raw
   `.byte`/`.word` opcode transcription as a shortcut around source
   reconstruction.
3. Add exactly one manifest entry for each of the 140 functions. Record its
   source, section, runtime address, size, reference SHA-256, and built
   SHA-256 using the existing schema.
4. Run `Invoke-FunctionMatch.ps1` separately for every function. A row may be
   promoted only when the report records equal sizes, both hashes, pinned tool
   versions, and `byte_match: true`.
5. Promote exactly those 140 CSV rows to `confidence = verified` and
   `source_status = hand_written_source`. Preserve every other field and every
   unrelated row.
6. Do not change proposed names or add semantic descriptions unsupported by
   primary evidence. The assembly proves byte identity, not high-level
   behavior or original-source equivalence.
